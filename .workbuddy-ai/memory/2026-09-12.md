## pi2 (pi.dev) 架构研究

- 产出：`pi2-pi-dev-代码架构与AgentHarness研究.md`（仓库根目录）
- 分析对象：`pi2-source-code/pi`（earendil-works/pi，v0.85.1，HEAD 71dca871b）
- 关键结论：
  - 11 个 package；构建拓扑序 chord→tui→telemetry→ai→agent→session-backends→protocol→client→server→coding-agent
  - `pi-agent-core` 新增 `AgentHarness`：三存储不变式（entries 不可变树 / values+lists 可变 / usage ledger 只追加）
  - 13 个 flat operation state leaf，每次转移写完整总态作为唯一重启点
  - 四原语 accept / drive / requestAbort / inspectExecution；accept 与 drive 分离
  - 意图→效果→结算两段提交；工具 `replay: "safe" | "never"`；并行工具按完成顺序 stage、按源顺序 materialize
  - **重要事实**：稳定 `pi` CLI 仍用经典 `Agent` + JSONL SessionManager；`AgentHarness` 只出现在 `src/experimental/`（session-worker / mini / services）
  - 分布式骨架：chord（facets/services/replicated state）+ protocol v8（CBOR 分帧）+ server/client + experimental/mini
  - 官方自陈缺口：J1（JSONL 无物理回收）、C1（RemoteSession 契约矛盾）、S12/R12（watchSession stub）、S3（search 无实现）、WP08
- 对比基线：pi1 `pi-mono` v0.67.68（agent 包只有 agent-loop/agent，无 harness 目录）
